## 📖 About

Sinhala Script Writer helps people write and edit scripts in Sinhala, from a phone or a web browser. A single backend serves both the app and a versioned REST API.

## ✨ Highlights

- 📝 Write and edit scripts in Sinhala
- 📱 Works on phone and web
- 🔌 REST API (`/api/v1`) built with Laravel
- 🐳 Containerised with Docker and deployed on Render

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Backend / API | Laravel (PHP) |
| Frontend | JavaScript web & mobile app |
| Deployment | Docker, Render |
